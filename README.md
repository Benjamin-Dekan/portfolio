# Portfolio

🔗 **Live site:** [benjamin-dekan-portfolio.vercel.app](https://benjamin-dekan-portfolio.vercel.app/)

A personal developer portfolio inspired by ocean bathymetry and deep-sea exploration, descending from sea level (0m) down to Challenger Deep (10,924m). Designed to showcase full-stack web applications, low-level embedded systems, and robotics automation projects with an interactive nautical aesthetic.

## Features

- **Dynamic Depth Telemetry:** Real-time depth gauge tracking your descent from 0m to 10,924m across actual bathymetric ocean zones as you scroll
- **Wave & Waterline Physics:** Custom animated SVG waves and a floating vessel component riding atop the swell at the surface
- **Mission Deployments:** Curated project cards showcasing full-stack engineering, lab robotics, and FPGA hardware designs with direct live and repo links
- **Interactive Sonar Radar:** A technical sweep-radar interface indexing proficiencies across low-level systems, modern web stacks, and developer tools
- **Expedition Logbook:** A terminal-style engineering background dossier detailing Computer Engineering coursework and foundational hardware-software interests
- **Deep-Sea Transmission Station:** Radio transmitter hub featuring a one-click clipboard email copy button and surface ascent thrusters to return to 0m instantly
- **Atmospheric Visuals:** Canvas and Three.js-powered marine snow, floating particles, and ambient bioluminescent sea life
